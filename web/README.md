# Web client

Минимальный SvelteKit-клиент для локального Go API.

Запуск API из корня проекта:

```bash
go run ./cmd/api
```

Запуск web-клиента:

```bash
cd web
bun run dev
```

Клиент отправляет выбранные файлы в Go API через `multipart/form-data`. API сохраняет их во временную папку, запускает проверку и удаляет временные файлы после ответа.
